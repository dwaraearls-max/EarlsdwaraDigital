# Earlsdwara Digital

Premium digital agency website for **Earlsdwara Digital** — built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Cinematic hero with gradient orbs, particles, and mouse spotlight
- Dark / light theme toggle
- Services, portfolio filters, case studies, process timeline
- Testimonials carousel, pricing, FAQ accordion, contact form
- Booking calendar with confirmation
- Project cost estimator / instant quote generator
- AI live chat assistant + WhatsApp chat
- Blog, sticky nav, scroll progress, scroll-to-top
- SEO metadata, Open Graph, Twitter cards, JSON-LD schema

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — run ESLint

## Stack

- Next.js App Router
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide Icons
